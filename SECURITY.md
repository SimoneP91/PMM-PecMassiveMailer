# Security

## Reporting a vulnerability

Report privately to the maintainers; do not open a public issue. Include the request id from the error body when one is involved: it points at the log line.

## What the service protects and how

**Target**: OWASP ASVS Level 2, OWASP API Security Top 10. The controls below are the ones the code enforces today; each later stage documents its own.

| Concern                            | Control                                                                                                                                                                                                                                                                     |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tenant identity                    | Derived from the API key on every request (`ApiKeyGuard`). No payload, path or query field can name a tenant.                                                                                                                                                               |
| API keys                           | 256-bit random, `pm_` prefixed so scanners recognise them. Stored as SHA-256 hashes in the config file, compared in constant time, shown once at generation.                                                                                                                |
| Mailbox passwords, webhook secrets | Read from the environment only, wrapped in `Secret` so no serialisation, log or error can print them. A missing secret stops the boot.                                                                                                                                      |
| Error responses                    | RFC 9457 problem documents. 5xx never carry an internal message; the client gets a request id, the log gets the error.                                                                                                                                                      |
| Request correlation                | `X-Request-Id` is honoured only when it matches a safe pattern; otherwise replaced.                                                                                                                                                                                         |
| Logging                            | Structured JSON, authorization and secret-looking fields redacted at the logger level as a second line of defence.                                                                                                                                                          |
| Configuration                      | Strict schemas (unknown keys rejected), cross-references checked, evaluated before any port or connection opens.                                                                                                                                                            |
| Transport                          | Helmet security headers. TLS termination is the platform's job (VPN / ingress).                                                                                                                                                                                             |
| Container                          | Non-root user, production dependencies only, pinned base image, health check.                                                                                                                                                                                               |
| Durability                         | MongoDB writes with `w: majority` + journal: a message recorded as sent survives a failover, so it is never sent twice.                                                                                                                                                     |
| Mailbox ownership                  | A batch names a mailbox by code; the code is resolved _for the calling tenant_ (`403` otherwise), so a client cannot send through another client's mailbox.                                                                                                                 |
| Upload limits                      | Per-tenant request ceiling enforced while streaming (`413`, nothing kept); at most 2,500 rows (tenant limit) under a hard 5,000; per-message encoded size against the mailbox limit. Files go to disk as they arrive, never into memory.                                    |
| File types                         | Detected from the first bytes, never from the declared content type; extension allowlist; executables and scripts refused (`415`); a file name cannot contain path separators.                                                                                              |
| Templates                          | Closed allowlist of elements and attributes, rejected not sanitised; no `<script>`, forms, frames, event handlers, remote images or CSS `url()`/`expression()`; links only `https:`/`http:`/`mailto:`; placeholders only where escaping protects (text, quoted attributes). |
| Placeholder values                 | `{{name}}` is HTML-escaped; `{{{name}}}` must itself pass the allowlist; subject values cannot inject headers (line breaks folded). Rendering is single pass: a value is never re-scanned for placeholders.                                                                 |
| Recipients                         | Only addresses served by an accredited PEC provider (known domains or MX) are accepted; a non-PEC address is rejected per row before anything is stored.                                                                                                                    |
| Idempotency                        | `Idempotency-Key` required: a retry cannot create a second batch; a key reused with a different body is refused.                                                                                                                                                            |
| Rate limiting                      | Per-tenant requests per minute (`429`, `Retry-After`).                                                                                                                                                                                                                      |
| Storage paths                      | Every path is built under `STORAGE_DIR` from validated part names; a path that escapes the root is a hard error.                                                                                                                                                            |

Planned for later stages, already designed: anti-SSRF validation of webhook URLs, HMAC-signed webhooks, append-only audit trail, tenant isolation tests in `test/security`, a worker liveness signal.
